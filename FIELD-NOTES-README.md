# Dubel Team Field Notes

Field Notes is the project-story layer of dubelteam.com.

## Editorial rule

Only publish a Field Note when it is based on a real Dubel Team engagement or product and there is enough first-hand material to add value beyond the short portfolio description.

Each note should explain:
- the real operating context;
- what Dubel Team actually owned or worked on;
- what made the work difficult or distinctive;
- what was learned from the engagement;
- verified numbers only when those numbers already exist in the public project record.

Do not create articles only to target keywords or increase page count. Do not invent client results, dates, staff counts, revenue, quotes, testimonials or outcomes. Update a note when the underlying public project record materially changes.

The initial collection contains 11 notes corresponding to the 11 projects in `work.html`.
